**C3.** The Note's behaviour is the requirement's, neither narrower nor wider:
- It selects a scrolling container and measures it across its scroll direction only. This is the definition ("any container that scrolls"), (1) ("measured by criterion 5 alone") and (5) ("its length along that direction is not measured").
- It measures a disabled control, and a self-test shows the control at the same size disabled and enabled. This is the definition ("a control included while it is disabled") and (6).
- It does not select a node whose only actions are focus, selection or copying, and it does select a link inside text. This is the definition ("Text whose only answer is focus, selection or copying is not one"; "a link inside text included") and (7). A non-text node with focus only answers no tap, press, drag or swipe with an action of the product, so the definition leaves it out too. The Note's "node" does not widen the requirement.
Under every reading of the Note there is one trigger, the screen measurement that the Verification line names.
