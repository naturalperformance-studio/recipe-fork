# Later — what the user asked for, not yet in an increment

Items the user raised at a demo and asked to keep for the future. Each names where it came from. When one goes into an increment, it moves there and leaves this list.

(v0.6 demo, 2026-10-03.) Also fixes: the v0.6 viewfinder framed portrait instead of 4:3 landscape; a second tap during the permission dialog reads as a refusal; an upside-down phone gives an upside-down shot.
- *(→ v0.8, T-094)* **Entry actions in the ⋮ menu.** On the book's entries, own and imported, "Export" and "Delete"/"Remove" move into a ⋮ menu on the title line. (v0.6 demo, 2026-10-03.)
- *(→ v0.9, T-100)* **A left-handed drag column.** (v0.4 demo, 2026-10-02.)
- **Flaky `AndroidConnectivityTest`** ("a connection that is lost and returns…") timed out once. (T-088 review, 2026-10-02.)
- *(→ v0.9, T-099)* **A reference to part of an ingredient.** A step's reference may name a share of the ingredient's quantity, not only the whole — e.g. garlic split between the marinade and the sauce of one recipe; the share scales with the recipe like the whole does. (Asked 2026-10-03, during v0.8.) Touches the persisted reference (`step_reference`, the recipe file's document, no migration needed). Older app versions reading new files, and the owner's existing book, are no concern: the owner is the only user and their phone holds test records only (said 2026-10-03) and spec/ FLOW-031, FLOW-032, DOM-007, which say a reference renders the ingredient's whole quantity — a departure to fold back with `/req-forge --sync`.
- User-made colour themes inside the app (the user, 2026-10-03: "Пользовательские темы пока в бэклог"); F1 ships one theme file and a theme choice only.
- *(→ v0.24)* **Animated image → clip** (MEDIA-004, last sentence): a GIF/WebP attached to a step stays a still photo; Media3 Transformer cannot decode animated images. Left out of v0.13 (2026-10-03).
- *(→ v0.23 groups and notes, v0.24 timers, v0.22 export name)* Noted by the lead while turning the owner's lemon-cake recipe into a file (2026-10-03), not asked for yet: **ingredient groups** ("Тесто" / "Глазурь"); **a note on a free-text ingredient** (a qualifier needs a dictionary entry today); **more than one timer in a step**; **an exported file's name**: Telegram strips the extension from a Cyrillic file name, so a recipe shared that way may not open — consider an ASCII-safe export name.
- **Synonyms on a dictionary entry** (the owner's idea, 2026-10-03; agreed as the FIRST task of the next increment after v0.14): an optional synonym list per language on the same line of the source (картофель → картошка, бульба; помидор → томат; powdered sugar → confectioners' sugar, icing sugar). The offer and the book's text search match synonyms; the offer shows the entry's label with the matched synonym beside it in a muted style («картофель · картошка»); recipes keep the entry id, so filters are unaffected; the generator refuses a synonym equal to another entry's label or synonym. Seed only the corpus misses (картошка, манка, курдючный жир, confectioners' sugar, hamburger buns) and томат; filling more later.
