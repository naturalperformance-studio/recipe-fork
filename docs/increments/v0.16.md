# v0.16 — The book and the card feel like a real Android app
**Status:** active
**Planned:** 2026-10-04 · **Shipped:** —

Goal, scenarios and out-of-scope below were approved by the user on 2026-10-04 (F-1 answered (a)). The user asked to work on UX before the theme (roadmap F1, which waits); seeded from the owner's complaints and `ux-roadmap.md` U1.

## Goal
The book swipes between your own and imported recipes, each recipe in it is a card with a large cover, its title and tags, and moving into a recipe and back is smooth and keeps your place in the list.

## What exists at the start
On `develop` @ dd8d900 (v0.15 shipped). One NavHost route; `LibraryScreen` shows the editor or the card by early return (`library/LibraryScreen.kt:141-189`), so the list's state is dropped and back has no preview. The book's header: a 64 dp title row with ⋮, two hand-built tabs (`ViewTab`, "Marked" / "Written here"), a full-width "New recipe" button, search and filter rows. Entries are hand-built rows with a small cover thumbnail (`CoverThumbnails.kt`) and the title; no tags. The card's bar is three text links (Back, Fork, Edit). The activity uses the platform `Theme.Material.Light.NoActionBar` and no `enableEdgeToEdge()`; the root is wrapped in `safeDrawingPadding()`. Loading shows nothing.

## Demo scenarios
1. Swipe the book left and right → it moves between the two views ("Written here" / "Marked"); the tabs above follow and switch on a tap too.
2. Every entry in the book is a card: the cover full width, below it the title, the tags and the state (draft…), a ⋮ on the right. A recipe without a cover is the same card without the picture.
3. Scroll the book down, open a recipe, come back → the list is where it was.
4. Start the back gesture on a recipe and hold → the recipe slides to show the book beneath; release or cancel.
5. The book's header is compact: title, ⋮, tabs, search; it scrolls away going down and returns going up. "New recipe" is a floating button at the bottom right.
6. A recipe has a top bar with a back arrow, its title and Edit / Fork; it collapses as you scroll. The status-bar icons are visible on every screen.
7. While the book or a recipe is loading, an indicator shows, not a blank screen.
8. Close the app on one view and open it again → it opens on the view you left.

## Out of scope
- Timers, haptics, the steps' text size (U2); the editor's own UX (U3), beyond becoming a navigation destination; filters, media, import and export (U4); settings screen (U5).
- The theme file and dark theme (F1); new components take their colours from today's theme.
- Renaming the views ("Marked" / "Written here") — a product question in `ux-roadmap.md`.
