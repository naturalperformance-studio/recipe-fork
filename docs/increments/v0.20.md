**Status:** planning

Goal, scenarios and out-of-scope approved by the user on 2026-10-04 (with v0.19 and v0.21): F1 of `serverless-roadmap.md` plus audit 28 of `ux-roadmap.md`. The user decided on 2026-10-03: one theme file in the repository; the app offers only the choice of theme (light / dark / as on the device).

## Goal
The app's colours change by editing one theme file, without touching Kotlin; there is a dark theme; the book's settings live on one screen.

## Demo scenarios
1. Changing a colour in the theme file and rebuilding changes it across the whole app; a short note says where the file is and how to edit it.
2. The book opens a "Settings" screen that shows current values: language, usual servings, theme, drag side, storage.
3. With "Dark", everything is readable and the status-bar icons are visible; ContrastTest covers both themes.
4. With "As on the device", the app follows the system's switch.

## Out of scope
- User-made themes inside the app (`later.md`).
- Replacing hand-built controls and motion (v0.21).
