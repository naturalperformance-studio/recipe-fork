# v0.22 — Nothing sticks together, ticks are felt, a recipe file opens from Telegram
**Status:** demo
**Planned:** 2026-10-04 · **Shipped:** —

Goal, scenarios and out-of-scope approved by the user on 2026-10-04 after touching the v0.21 build (with v0.23 and v0.24). On 2026-10-09 the user added opening a recipe file from Telegram as a must-have (scenarios 6–8, T-166) and started the run.

## Goal
On the card and in the book nothing sticks together, the owner's phone feels the ticks, a `.recipefork` file opens in the app straight from Telegram or a file manager, and the tails left by v0.18–v0.21 are picked up.

## Demo scenarios
1. On the card, − and + are one segmented button [ − | + ]; each half is 56 dp, is announced and works as today.
2. In the book, search and sort share the first line; the row of filter chips sits below with a clear gap (about 12 dp); nothing touches the field at any font size.
3. With the system's touch feedback on, servings −/+ and dragging a row give a short tick and the timer buttons a click on the owner's phone (checked on the device over USB); with it off, nothing vibrates.
4. A recipe exported and sent through Telegram opens again: the file's name is ASCII, its extension kept.
5. After the camera, the crop's "Cancel · Retake · Done" fit one line in Russian at 2× font on a 320 dp screen.
6. In Telegram, tapping a received `.recipefork` offers Recipe Fork; the app opens in its own window (not inside Telegram) and the recipe is in the book (or the app says it is already there).
7. The same file saved to Downloads opens the same way from the phone's file manager.
8. A photo, a PDF, a ZIP or any other file that is not a `.recipefork` never offers Recipe Fork.

## Out of scope
- New recipe capabilities, undo of deleting, "done" marks (v0.23); several timers in a step, an animated image as a clip (v0.24).
- Handing the build to people (`later.md`).
- Offering the app for files of unknown type that are not named `.recipefork` (the user, 2026-10-09: only recipe files). Opening a file in the standard (server) build stays off as before.

### T-166 — A recipe file opens from Telegram and file managers
**Status:** done
**Serves:** 6, 7, 8 · **Core:** no · **Depends on:** —
**Expected files:** `AndroidManifest.xml` (the recipe-file intent filters), `file/RecipeImport.kt` (`RecipeFileIntents`), `MainActivity.kt` (`follow`, task handling), tests.
**Criteria:**
- An `ACTION_VIEW` of a `content:` or `file:` address whose path ends in `.recipefork` resolves to the app whatever type it declares — the product's type, `application/zip`, `application/octet-stream`, `text/plain`, `*/*` or none (FLOW-064). Asserted against the merged manifest (Robolectric `PackageManager.queryIntentActivities`) for a Telegram-shaped address (`content://org.telegram.messenger.provider/media/…/Telegram Files/lemon-cake.recipefork`, spaces included), a file manager's and a `file:` one.
- An `ACTION_VIEW` declaring the product's type `application/vnd.recipefork.recipe+zip` resolves to the app whatever the address looks like (no name in it).
- An `ACTION_SEND` with `EXTRA_STREAM` declaring the product's type resolves to the app and imports exactly like a view.
- Nothing else resolves: `image/jpeg`, `application/pdf`, `application/zip` and `application/octet-stream` with a path not ending in `.recipefork` (or with no name in it) do not offer the app — each a test.
- An opened file shows the app in its own task, not stacked inside the sender's: after the import the book shows the recipe, or says it is already there, or gives the refusal's reason, as the in-app import does today; a second file opened while the app runs is followed too.
- The lead checks on the owner's phone over USB before the demo: a file tapped in Telegram offers the app and imports; if the phone's Telegram sends something these filters miss, that is a fix round.
**Notes:** Developer run 1 done (5f32357); the permission system refused the agent's `git commit`, so the lead committed its work with the user's leave (2026-10-09). Review 1: fix — a forward of an address the app holds no grant for crashed instead of refusing; folded in: no re-import when reopened from Recents, the upper-case extension. Review 2: pass; merged 2026-10-09. The owner's-phone check over USB is still due before the demo. Telegram's `openForView` sets the type from the extension's system type, else the document's type, else `text/plain`; today's filters pair a path with three types only, so a Telegram view with any other type (or `text/plain`) matched nothing (the user, 2026-10-09: "there was no option to open with our app").

## Decision log

- 2026-10-04 `decided` Vibration follows the system's touch-feedback setting (the user, after first answering "let it be"; then the ticks were not felt even with every system vibration on).
- 2026-10-04 `assumed` The cause is the view's `performHapticFeedback` path, silent on the owner's Samsung; ticks go to the `Vibrator` directly with touch attributes, so the system setting still governs them.
- 2026-10-09 `assumed` Recipe files arrive at a small invisible activity that hands them to the app's own task; the app no longer offers itself in its own export share sheet (the recipe is in the book already).
- 2026-10-09 `assumed` The extension is recognised in paths holding up to twelve dots; a longer path is recognised only by the product's type.
- 2026-10-09 `assumed` A file arriving while the phone's camera is open over the card leaves the camera and shows the book with the import's result.
- 2026-10-09 `assumed` The servings halves stay tonal (as before); the connected look is built from two theme surfaces — outer corners fully rounded, inner 8 dp, a 2 dp seam — since material3 1.4.0 has no public connected button group.
- 2026-10-09 `assumed` The servings count keeps 8 dp before the group and wraps onto a second line at 2× font rather than being clipped.
- 2026-10-09 `assumed` Reopening the app from Recents repeats neither a file's import nor the jump to a timer's step.
- 2026-10-09 `assumed` The exported name: Russian spelt in Latin by the common passport scheme (щ → shch, ъ/ь dropped), accents removed, every run of other characters one hyphen, at most 80 characters; a title with nothing to spell gives `recipe.recipefork`.
- 2026-10-09 `assumed` At a large font the crop bar wraps: Cancel stays at the start, Retake and Done move to the next line's end, Done always last; at 1× it is one line as before.
- 2026-10-09 `assumed` An export name counts as all-caps when every letter of the title is upper case (so "Я" gives "YA"; Latin acronyms stay as they are); Ukrainian и and г keep the Russian spelling (i, g).
