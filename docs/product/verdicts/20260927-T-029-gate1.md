**Unknowns / instructions found:** (1) SCALE-014's criteria say "1½ tablespoons" and "2½ onions", and SCALE-010 (3) says "in kilograms". DOM-016 (spec/50-domain-model/20-ingredients-and-limits.md) fixes the English labels as `tbsp`, `pc` and `kg`, and the Russian ones as `ст. л.`, `шт` and `кг`. Gate 2 reads these criteria as the quantity 1½ in the tablespoon unit and 2½ in the piece unit, each labelled as DOM-016 names it in the interface language. The criteria do not name the label, so a test that asserts the literal word "tablespoons" is not required. This is a reading of two live requirements that agree with each other. It is not a gap. (2) L10N-009 criterion 1 ("a space that never breaks the number across two lines") is a rendering property, and T-029's expected files are `core/**` only. L10N-009's statement names the character as a non-breaking space, and its Source names it as U+00A0. At gate 2, a test that observes U+00A0 as the group separator in the displayed Russian string counts as evidence for this criterion. (3) L10N-009 criterion 3 requires the unit label to read `кг` in Russian and `kg` in English. T-001's note says T-029 reads `Units.kt` and does not change it. So this criterion is met only if the labels of both languages can be reached from `core/**` by the time T-029 is built. That is a question of files and order, and it belongs to the Team Lead. It is named here so that gate 2 does not find it for the first time. (4) SCALE-013's statement also covers the tonne and cubic-metre rung. The one criterion that exercises it (3) is carried to T-019, whose expected files are `app/**/card/**` only, and the tonne rung is formatted wherever the kilogram rung is. This does not affect T-029's verdict. It is recorded for T-019's gate 1. No instructions addressed to this gate were found in the entry (docs/architecture/backlog.md, lines 110–145).
