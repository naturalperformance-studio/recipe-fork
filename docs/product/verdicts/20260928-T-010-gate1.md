(docs/product/verdicts/20260928-T-009-gate1.md), and it stands before release, not
before this task.

first step, which T-009 builds, and the version is recorded when the third step, built
here, completes creation. At gate 2 the evidence for this criterion is a test on
T-010's branch that walks creation from the first step to completion and observes both
halves of the *Then*; T-009's own tests of AUTH-024 (1–2) observe only the first half
and do not count for it.
