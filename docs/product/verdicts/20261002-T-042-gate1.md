**C4 — behaviours in the entry and the requirement behind each**
| Behaviour described | Requirement |
|---|---|
| A repeat of a sending (same content, same revision) that already made a fork is answered with that fork, whatever the server's content has become, and no second fork is made | FLOW-066 (statement, 4), FLOW-008 (7) |
| That check is made before sameness of content | FLOW-066 (statement: "checked first"); spec ADR 20261001-a-fork-already-made-is-answered-first |

| A repeat of a stored, unanswered sending sent again unedited makes no fork and is answered as sent | FLOW-066 (1) |
| The answer to such a sending carries the state the server holds | FLOW-066 (statement: "show on the device the state the server holds it in"; 3) |
| Sameness is over the whole content; before wave 5 that is the content document | FLOW-066 (statement: "every field and every media item") |
| A content that differs in one character, in any kind of field, is not answered as the same | FLOW-066 (5) |
